The eight skills.

Seven shape the work around a task. /leonardo does the task itself.

  1. /higherRewrites your task to ask for the outcome one level up.
  2. /deeperRewrites your task to use what a top professional would use.
  3. /widerBrings in the methods of other fields, plus a red team.
  4. /signal-first-planPuts a countable signal on every exit before you build.
  5. /debugging-by-constraintsGathers facts first, then keeps the one cause that fits all.
  6. /debug-retroTurns each time you had to step in into a lasting rule.
  7. /leonardoDoes open-ended work and tries to beat the answer your agent gives by default.
  8. /defendQuizzes you on what a session decided, and grades your answers.

/higher, /deeper and /wider hand you a rewritten prompt in the chat, like the example above, and you reply go in the same chat to run it. The full description of each skill is in the README.

How a line gets in.

A skill is a file of written instructions for the agent. The rule for a new line: a real session transcript or a test run must show the result that line would change. A claim that fails is kept in the GitHub release notes, with the reason it failed. When a line goes in before it is tested, the release notes say so.

Rejected in release v0.5.0: a claim from Andreas Zeller's The Debugging Book, checked against /debugging-by-constraints

Leave a comment at the fixed location that explains why the code now looks this way.

Rejected: sharper-skills allows code comments only for constraints from outside the code, so the commit message records the cause of the bug instead.

Published in release v0.12.0: /leonardo against the plain agent (the same agent with no skill). Three models judged each pair blind and picked one answer to ship.

Install.

  1. Any agent, with the Vercel Labs skills CLI (Node.js 22.20 or later). Add -g to install for every project.

    npx skills add rajnandan1/sharper-skills

  2. Claude Code, all eight as a plugin. Run the first command, then the second.

    /plugin marketplace add rajnandan1/sharper-skills
    /plugin install sharper-skills@sharper-skills

  3. By hand: copy a skill's folder from skills/ into ~/.claude/skills/ (Claude Code), ~/.agents/skills/ (Codex) or ~/.cursor/skills/ (Cursor).

To start a skill, type its name and the task: /deeper add retry logic. Codex uses $deeper. /signal-first-plan and /debugging-by-constraints also start on their own when your task matches them.
